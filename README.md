
## Kubernetes CI/CD Capstone Project: AWS EKS and ECR integrated, version-controlled.

 I have created a complete CI/CD pipeline with Jenkins that increment version, build artifact for java-maven application, build docker 
 image for that application and push it to the AWS ECR repository, then deploy the latest application to the EKS cluster, and finally 
 Commit the version update to Git.

## Technologies I have used here:
**Kubernetes, 
  Jenkins, 
  AWS EKS and ECR,
  Java, maven,
  Docker,
  Git &
  Linux**


## What I have learned:
  1. How to create an Elastic Container Registry on AWS and how it works.
  2. How to create credentials and access the ECR registry via Jenkins.
  3. How to Deploy application on the EKS cluster via Jenkins.
